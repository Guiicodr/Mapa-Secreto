# Mapa Secreto

Pequeno projeto React + Vite + Tailwind que mostra pontos turísticos pouco conhecidos em São Paulo.

Paleta: amarelos com detalhes em verde e azul.

Quick start:

```bash
cd Mapa-secreto
npm install
npm run dev
```

Run development API server (optional):

```bash
cd server
npm install
npm start
```
