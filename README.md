# 📍 Mapa Urbano

A curated, interactive web application designed to help users discover hidden gems, secret spots, and unique locations across the city. The interface dynamically adjusts its thematic aesthetic based on user-selected profiles (e.g., Nightlife, Family, Kids).

---

## ✨ Features

- **Dynamic Visual Themes**: Real-time theme transitions based on the active user profile.
- **Instant Search & Filtering**: Filter locations seamlessly by category or search by spot name and neighborhood.
- **Interactive Cards**: Clean, modern UI displaying key location specs and direct Google Maps integrations.
- **Responsive Design**: Tailored layout using Tailwind CSS for fluid viewing across mobile, tablet, and desktop screens.

---

## 🛠️ Tech Stack

- **Framework**: React.js
- **Styling**: Tailwind CSS
- **Build Tool**: Vite
- **Icons & Typography**: Custom CSS styling with system fallback fonts
